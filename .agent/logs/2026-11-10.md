## 2. 변경 파일 및 상세 작업 내역

### 1) 루트 모노레포 환경 구성
- `pnpm-workspace.yaml`: `apps/*`, `packages/*` 워크스페이스 패키지 경로 및 `onlyBuiltDependencies` 선언
- `turbo.json`: `build`, `dev`, `lint`, `typecheck`, `clean` 파이프라인 구성
- `package.json`: 루트 스크립트(`build`, `dev`, `lint`, `typecheck`, `clean`) 및 devDependencies(`turbo`, `prettier`, `rimraf`, `typescript`) 구성
- `.gitignore`: Node, Next.js, NestJS, Turborepo, .env 파일 예외 처리
- `.env.example`: 프론트엔드 및 백엔드 환경변수 템플릿 생성

### 2) 공통 패키지 구축 (`packages/`)
- `packages/tsconfig/`: `@ideamory/tsconfig`
  - `base.json`, `nextjs.json`, `nestjs.json` 공통 TypeScript 설정
- `packages/eslint-config/`: `@ideamory/eslint-config`
  - TypeScript, ESLint, Prettier 통합 린팅 규칙
- `packages/api-spec/`: `@ideamory/api-spec`
  - Zod 기반 `CreateMemoSchema`, `ErrorResponseSchema` DTO 및 타입 SSOT 구성
- `packages/db/`: `@ideamory/db`
  - Supabase 클라이언트 팩토리(`createSupabaseServiceClient`) 구성

### 3) 애플리케이션 스캐폴딩 (`apps/`)
- `apps/web/`: Next.js 15 (React 19) 프론트엔드
  - FSD(Feature-Sliced Design) 아키텍처 디렉터리 구축 (`src/app/`, `src/features/`, `src/entities/`, `src/shared/`)
  - `src/shared/api/api-client.ts`: `X-Trace-Id` 자동 주입 인터셉터를 탑재한 순수 REST Axios 클라이언트 생성
  - Server Actions 사용 금지 정책 준수
- `apps/api/`: NestJS 11 백엔드
  - `src/main.ts`: CORS 및 `X-Trace-Id` 노출, Swagger UI(`/api/docs`), ValidationPipe 설정
  - `src/common/interceptors/trace-id.interceptor.ts`: 6자리 Hex Trace ID 발급 및 로깅
  - `src/common/filters/http-exception.filter.ts`: 표준 `ErrorResponseDto` 응답 필터
