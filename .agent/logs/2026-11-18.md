## 백엔드 로깅·트레이싱 명세서 v3 구현 및 `@sentry/nestjs` 연동 (`feat/logging-aop-drizzle-sentry`)

- **[Observability - Sentry 조기 초기화 및 환경변수 템플릿 추가]**:
  - `.env.example`에 `# [Observability - Sentry]` 및 `SENTRY_DSN=""` 항목을 추가함 (`.env` 파일은 미수정).
  - `apps/api/package.json` 및 `pnpm-lock.yaml`에 `@sentry/nestjs` 패키지를 추가함.
  - `apps/api/src/instrument.ts`를 생성하여 `SENTRY_DSN`이 설정된 경우에만 `Sentry.init`을 수행하도록 구성함 (`tracesSampleRate`는 프로덕션 0.2, 개발 1.0).
  - `apps/api/src/main.ts` 최상단(`1`번 줄)에 `import "./instrument";`를 배치하고, 부트스트랩 시 `setDatabaseLogger(new AppDrizzleLogger())`를 등록함.
- **[로그 새니타이저 및 AOP 메서드 추적 데코레이터 구현]**:
  - `apps/api/src/common/utils/log-sanitizer.util.ts`를 생성하여 `sanitizeForLog` 및 `safeStringifyForLog`를 구현함 (민감 키 `[MASKED]` 치환, 100차원 이상 숫자 배열 `[vector(768)]` 축약, 500자 초과 문자열 `...(truncated)` 절삭, 순환 참조 `[Circular]` 처리, Fail-Safe `[SerializationError]` 반환).
  - `apps/api/src/common/decorators/log-trace.decorator.ts`를 생성하여 `@LogTrace(options?)` 메서드 데코레이터를 구현함 (`traceStore` 8자리 Trace ID 접두어 + `[ENTRY]`/`[EXIT]`/`[ERROR]` 및 소요 시간 ms 출력).
  - `apps/api/src/modules/auth/auth.service.ts`, `apps/api/src/modules/category/category.service.ts`, `apps/api/src/modules/memo/memo.service.ts`, `apps/api/src/modules/ai/ai.service.ts`, `apps/api/src/modules/ogp/ogp.service.ts`의 주요 비동기 유즈케이스 메서드에 `@LogTrace()`를 적용함.
- **[Drizzle 원시 SQL 로깅 및 Trace ID / Sentry 5xx 연동]**:
  - `packages/db/src/client.ts`에 `DrizzleQueryLogger` 인터페이스와 `setDatabaseLogger` 등록 함수를 추가하고, `drizzle(sqlClient, { schema, logger: { logQuery(...) } })`를 연결함.
  - `apps/api/src/database/drizzle.logger.ts`를 생성하여 `AppDrizzleLogger`가 8자리 Trace ID와 `safeStringifyForLog`를 사용해 `[Drizzle:Query] SQL: ... | PARAMS: ...`를 출력하도록 구현함.
  - `apps/api/src/common/interceptors/trace-id.interceptor.ts`에 `Sentry.getCurrentScope().setTag("trace_id", traceId)` 및 HTTP 응답 상태 코드(`res.statusCode`) 로깅을 추가함.
  - `apps/api/src/common/filters/http-exception.filter.ts`에 `5xx` 예외 발생 시 `Sentry.withScope`로 `trace_id`, `error_code`, HTTP 메서드·경로를 태깅하고 `Sentry.captureException(exception)`을 호출하도록 추가함.
